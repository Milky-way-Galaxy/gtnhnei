# GTNH Calculator Data Exports

This repository hosts exported binary data files for use with the [GTNH Calculator](https://github.com/ShadowTheAge/gtnh/).

These files are generated using the export pipeline described in the [GTNH Calculator repository](https://github.com/ShadowTheAge/gtnh/tree/main/export).

## Important Notes

- **Binary Format**: The exported files are binary and cannot be easily diffed or version-controlled in the traditional sense.  
  New versions must be created starting from the commit where this README was added to ensure a clean history.
  
- **Copyright Disclaimer**:
